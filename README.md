# Portfolio — Ruddarraju Bhuwaneshwari

My personal portfolio website, built with React. Live at: https://bhuwaneshwari22.github.io/portfolio/

## Tech Stack

- React 18
- React Router (HashRouter) for client-side navigation
- gh-pages for deployment to GitHub Pages
- Custom CSS (no framework) — Space Mono + Syne fonts

## Pages

**Home**
- Hero introduction
- About Me
- Research Interests (AI, Machine Learning, Deep Learning, NLP, Generative AI, Cyber Security)
- Skills (Python, Java, C, Deep Learning, NLP, OOP, Machine Learning, SQL, GitHub, Data Structures)
- Personal/contact details

**Projects**
- Multilingual Fake News Detection (mBERT + LIME, English & Telugu)
- Utility Bill Management System (Java Swing/AWT desktop app)
- Form Validator (HTML/CSS/JavaScript)

Each project card links out to its own GitHub repo.

## Running Locally

```bash
npm install
npm start
```

## Deployment

```bash
npm run deploy
```

This builds the app and pushes it to the `gh-pages` branch, publishing it to GitHub Pages.
